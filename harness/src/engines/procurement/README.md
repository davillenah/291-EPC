# `procurement`

Status: **in development**

Procurement engines: BOQ, datasheets, RFQ. `boq` (MIG-39c: draft bill of quantities, quantities only) and `datasheets` (MIG-39d: draft datasheet records, catalog candidates per requirement, all pending review) and `rfq` (MIG-39e: draft request for quotation, empty supplier response fields, no prices) exist, with tests and status in development.
