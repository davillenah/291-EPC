# Error catalogue

Generated by `python harness/tools/build/error_catalogue.py` from each engine's `messages.py`; do not edit by hand (GEN-08, ADR-0039).

A code is stable: its text may be reworded, the code is never reused for another meaning. `err_*` codes are raised by the engine (`<Engine>Error`, with `code`, `en` and `es`); the other codes are warnings and labels the engine puts in its result. `{name}` is filled in from the call.
